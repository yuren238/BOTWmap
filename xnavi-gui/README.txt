========================================
  XNAVI v3.2.2 · 旷野之息实时定位导航
  Savage Wind 适配版
========================================

【这是什么】
电脑上的定位导航工具：读取游戏内存，把林克的实时位置
显示在地图上。支持 Cemu / Ryujinx / Eden / Savage Wind。

【快速开始（Savage Wind）】
1. 启动 Savage Wind 并进入游戏（进到能走动的地图里）
2. 双击 Xnavi.exe，平台下拉选「Savage Wind」
3. 点「开始定位」，等日志出现「真身锁定」
4. 点界面上的打开地图按钮，红点即当前所在位置

存档路径留空会自动找 <游戏目录>\Savage Wind\save；
装在别处时在设置页手动指定 save 目录即可。

【本包已自带地图】
包内 app 文件夹就是地图页面（含宝箱/装备/任务的显示逻辑），
和 Xnavi.exe 放在同一目录即可，不需要另外下载地图包。
★ 请勿删除 app 文件夹，删了地图会打不开。
底图瓦片从 botw.yalin.site 在线加载，首次打开需要联网；
断网时底图空白，但标记点、存档进度、红点定位仍然可用。

【红点不动 / 提示请在游戏内移动角色】
首次定位需要走几步来确认锁定的是林克本体（不是内存里的
静态副本）。在游戏里走 3~5 步，状态会变成「已完全锁定」。

【换了存档后，地图上宝箱显示已开启】
这是浏览器本地缓存的上一档记录，点存档面板的 🧹 图标
（清空本地探索度）即可清除。正常换档现在会自动清。

【常见问题】
· 点了定位没反应？——先确认游戏已启动并进入 3D 地图场景
· 地图不显示红点？——浏览器打开 http://127.0.0.1:8766/pos
  能看到一串代码 = 定位正常，问题在浏览器（多为代理工具）；
  看不到 = 定位服务没起来，在 GUI 日志里找 [server] 开头的行
· 手机/平板当第二屏 —— 同一 WiFi 下打开
  http://<电脑IP>:8766/botw/?follow=1（启动日志里有 LAN 地址）
· 详细适配说明 —— 见 ADAPT-SAVAGEWIND.md

【安全声明】
只读游戏内存，不注入、不修改游戏、不联网上传任何数据。
